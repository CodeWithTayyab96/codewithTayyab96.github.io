Smart Street Light

MIT
iot system · esp32 + flask

An ESP32 detects passing vehicles with an IR sensor and drives street lighting automatically — with a live web dashboard and two-way communication to the device.

what stands out
  • The firmware keeps working if the server goes offline — local day/night fallback
  • Two-way: the device POSTs events, Flask pushes commands back to it
  • Sensor debounce, three light modes, X-API-Key on every endpoint
  • Auto-switches between SQLite locally and Supabase when deployed
  • Six documented REST endpoints with example payloads
